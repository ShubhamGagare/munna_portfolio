# HandCraftUI components

Button, Card, and the border-radius utility are copied from Shubham Gagare's
`handcraft-ui` 1.0.3 npm release, following its copy-in distribution model.

Source: https://www.npmjs.com/package/handcraft-ui/v/1.0.3
Upstream README declares MIT licensing. Author attribution: Shubham Gagare.

Local adaptations: relative utility imports, stable per-component border radii,
Radix Slot for accessible `asChild` behavior, correct heading ref type, and
merging consumer styles. These components power portfolio actions and the
interactive HandCraftUI showcase. No package CLI or lifecycle script is run.
